# Mimi's Birthday Website ♡

A fun, cute, and emotional birthday website made with plain HTML, CSS, and JavaScript. No build tools or paid services required.

## Preview it on your device
1. Download and unzip `mimi-birthday-website.zip`.
2. Open the folder.
3. Open `index.html` in a browser.

## Personalise it first
Open `index.html` in any text editor and change:
- The birthday messages and letter text.
- The three memory cards to include your actual inside jokes or memories.
- The sign-off (`your favourite menace`) to your own nickname.

You can change colours near the top of `style.css` in the `:root` section.

## Publish it free with GitHub Pages
1. Sign in to GitHub or create an account at https://github.com.
2. Create a new **public** repository, for example `mimi-birthday`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root (the main page, not inside another folder).
4. Open the repository's **Settings**.
5. In the sidebar, choose **Pages**.
6. Under **Build and deployment**, set the source to **Deploy from a branch**.
7. Choose branch **main** and folder **/(root)**, then save.
8. Wait a minute or two. The Pages section will show your website URL, usually:
   `https://YOUR-USERNAME.github.io/mimi-birthday/`
9. Open the URL to test it, then send the link to Mimi.

## Troubleshooting
- If you see a 404, confirm `index.html` is in the repository root and GitHub Pages is enabled.
- If changes do not appear, wait a minute and refresh.
- The decorative font loads from Google Fonts; if it is blocked, the site still works with fallback fonts.
- The website does not collect or send any personal data.
